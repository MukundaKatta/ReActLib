# Contributing to ReActLib

## Setup

```bash
git clone https://github.com/MukundaKatta/ReActLib.git
cd ReActLib
make dev
```

## Development

- Run tests: `make test`
- Lint: `make lint`
- Format: `make fmt`

## Pull Requests

1. Fork the repository
2. Create a feature branch
3. Add tests for new functionality
4. Ensure all tests pass
5. Submit a PR with a clear description
